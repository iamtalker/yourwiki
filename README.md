# 유어위키 (YourWiki)

누구나 자기 컴퓨터에서 **나무위키의 모든 글(문서 약 180만 개)** 을 가진 위키를 원터치로 띄울 수 있게 해 주는 도구입니다.
편집·추가·삭제가 되는 진짜 위키이고, 나무위키 최신판으로 문서를 갱신할 수도 있습니다.
데이터는 공개 보존처(archive.org)에서 키트가 직접 받아 옵니다. 제작자는 데이터를 호스팅하지 않습니다.

> 유어위키는 나무위키 운영사와 관계없는 비공식 도구입니다. "나무위키" 이름과 로고를 사이트 이름으로 쓰지 마세요.

## 사용법 (Windows)

1. 이 폴더를 원하는 곳에 둡니다. 디스크 여유 공간이 **45GB 이상** 필요합니다(2026판 기준: 받는 파일 5GB, 설치 후 약 35~40GB. 2021판은 15GB).
2. **`유어위키.bat`** 을 더블클릭하면 브라우저에 **관리판**이 열립니다(처음엔 필요한 도구를 먼저 받습니다).
3. 관리판에서 **[설치]** 를 누릅니다. 받기·변환·검색 색인까지 1~2시간 걸립니다. 끊겨도 다시 누르면 이어서 합니다.
4. **[켜기]** → "위키 준비됨"이 뜨면 **[위키 열기]**. 오랜만에 켤 때는 준비에 몇 분 걸릴 수 있습니다.
5. 끌 때는 **[끄기]** 를 누른 뒤 관리판 창을 닫으세요. 그냥 닫았더라도 다음에 관리판을 열 때 남은 프로그램을 자동으로 정리합니다.

- **데이터**: 2026-08 나무위키를 나무마크로 되돌린 것(약 180만 개). 연구·보존용으로 나무위키 공식 2021 덤프 원문(약 87만 개, 틀과 기여자 목록 포함)을 원하면 `scripts\install.ps1 -Edition 2021`.
- **동기화**: 끄기 / 요청한 문서만 / **자동 따라잡기(기본: 위키가 켜져 있는 동안 나무위키 최근 변경을 따라감)**.
  위키의 각 문서 위쪽 「🔄 나무위키 최신판으로 갱신」 단추를 누르면 그 문서를 나무위키에서 새로 받아 옵니다.
  robots.txt 를 지키고 6초에 1건 이하로만 요청하며, 캡차·차단이 보이면 즉시 멈춥니다. 같은 문서는 24시간에 한 번만 받습니다.
- 명령줄에 익숙하면 `scripts\install.ps1`(설치), `scripts\start.ps1`·`stop.ps1`(켜기·끄기)을 직접 실행해도 됩니다.

설치 후에는 인터넷 없이도 동작하고, 문서를 볼 때 외부 서비스에 접속하지 않습니다.
openNAMU 가 원래 CDN·유튜브·트위터 등에서 불러오던 것을 중계 서버(`scripts/offline_proxy.py`)가
동봉 파일(`assets/`)로 바꾸거나, 영상·SNS 삽입은 "▶ ○○에서 보기" 링크로 바꿉니다
(누를 때만 외부로 연결). 문서 원문은 바뀌지 않습니다.

설치 마지막 단계에서 검색 색인을 만듭니다. 문서가 87만 개라 수십 분 걸리고 CPU 를 많이 씁니다.

## 무엇을 받아 오나

| 항목 | 출처 | 검증 |
|---|---|---|
| 나무위키 덤프 2021-03-01 | archive.org 직접 다운로드 | MD5 |
| openNAMU (위키 엔진, BSD-3) | github.com/openNAMU | SHA-256 |
| 파이썬 임베디드판 | python.org | SHA-256 |
| 7zr (압축 해제) | github.com/ip7z/7zip | SHA-256 |
| aria2 (이어받기 되는 다운로더, GPL-2) | github.com/aria2 | SHA-256 |

키트에 동봉된 것: `assets/` (KaTeX·highlight.js 등 MIT/BSD, Material Icons Apache-2.0),
`extras/` (보충 틀, CC BY-NC-SA 2.0 KR).

받을 곳과 해시는 `sources.json` 에 있습니다. 더 새로운 덤프가 공개되거나 보관처가 바뀌면
여기에 한 줄 추가하면 됩니다(`"type": "http"`, 또는 토렌트를 쓰려면 `"type": "torrent"` 와 `select_file`).
위에서부터 차례로 시도하고, 어느 경로로 받든 MD5 로 검증합니다.

## 라이선스와 저작자 표시

> **이 데이터는 CC BY-NC-SA 2.0 KR입니다. 상업적 이용은 금지됩니다.
> 이 키트를 사용해 광고를 붙이거나 상업적으로 운영하는 것은 라이선스 위반입니다.**

- 문서 텍스트: **CC BY-NC-SA 2.0 KR**. 저작권은 각 문서의 기여자에게 있습니다.
  키트는 모든 문서 끝에 원 나무위키 주소, 기여자 목록, 라이선스 고지를 자동으로 넣습니다.
  - **BY**: 원 문서 주소와 기여자를 지우지 마세요.
  - **NC**: 영리 목적으로 쓸 수 없습니다. 키트에는 광고 기능이 없습니다.
  - **SA**: 이 데이터로 만든 결과물도 같은 라이선스로 공개해야 합니다.
- 넘겨주기 문서에는 본문을 바꾸지 않기 위해 고지를 넣지 않습니다.

## Docker로 서버에 올리기 (베타)

```bash
git clone https://github.com/iamtalker/yourwiki && cd yourwiki
docker compose up -d                 # 처음엔 데이터 받기·설치로 1~2시간
docker compose logs -f               # 진행 확인
```

- 설정은 환경 변수로 바꿉니다: `PORT`(바깥 포트, 기본 3000), `SYNC`(auto/queue/off), `COLOR`(머리글 색), `EDITION`(비우면 2026판).
  예) `PORT=8080 SYNC=queue docker compose up -d`
- 위키 DB와 받은 데이터는 `./yourwiki-data/` 에 저장되어, 컨테이너를 지우거나 새 버전으로 바꿔도 남습니다.
- 공개 전에 할 일(관리자 가입, 편집 권한, HTTPS)은 아래 리눅스 절과 같습니다.

## 리눅스 서버에 설치하기 (베타)

서버(보통 리눅스)에 올리려는 사람을 위한 스크립트가 `server/` 에 있습니다. 윈도우에서 **`서버설치가이드.bat`** 을 누르면 이 안내를 보기 좋게 정리한 페이지가 열립니다.
필요한 것: python3(3.8 이상), 7z(p7zip-full), curl, 디스크 45GB 이상.

```bash
git clone https://github.com/iamtalker/yourwiki yourwiki-kit && cd yourwiki-kit
bash server/install.sh                  # 엔진·데이터 받기, 해시 검증, 문서 넣기 (끊겨도 다시 실행하면 이어서)
bash server/yourwiki.sh start           # 켜기 (0.0.0.0:3000, 나무위키 동기화 자동)
bash server/yourwiki.sh status          # 상태
sudo bash server/yourwiki.sh install-service   # 부팅 때 자동 시작(systemd)
```

- 바깥 주소·동기화는 환경 변수로 바꿉니다: `LISTEN=127.0.0.1:3000 SYNC=queue bash server/yourwiki.sh start`
- 처음 켤 때 검색 색인을 만드느라 오래 걸리고 CPU 를 많이 씁니다. 그동안에도 문서는 볼 수 있습니다.
- HTTPS 는 nginx·Caddy 같은 역방향 프록시를 3000번 앞에 두면 됩니다.
- 첫 가입자가 관리자가 됩니다. 공개 전에 편집 권한(누구나/가입자만/읽기 전용)을 관리자 설정에서 정하세요.
- 이 스크립트들은 아직 실제 리눅스 서버에서 충분히 시험하지 않았습니다. 문제가 있으면 이슈로 알려 주세요.

## P2P 공유 (1.2, 베타)

갱신기는 나무위키 서버 부담 때문에 6초에 1건만 받아서, 덤프 이후 바뀐 문서를 따라잡는 게 가장 느린 부분입니다.
관리판의 **P2P 공유**를 켜면 참여한 유어위키끼리 나무위키에서 받은 문서를 **중계소**를 거쳐 나눠 갖습니다.

- 각 위키는 대기열을 무작위 순서로 받고, 친구나 검증된 ID 가 이미 받은 문서는 건너뜁니다. 그래서 서로 다른 문서를 받아 나누고,
  참여자가 N곳이면 전체로는 약 N배 빠르게 따라잡습니다. 위키마다 나무위키로 가는 요청(6초에 1건)은 그대로입니다.
- **ID**: 각 위키는 처음 켤 때 서명 열쇠(Ed25519)를 만들고 공개 열쇠가 ID 가 됩니다(`wiki/p2p_key.json`, 남에게 주지 마세요).
  주소가 아니라 ID 로 구별하므로 주소가 바뀌어도 상관없고, 친구는 관리판에 **ID 를 한 번만** 적으면 됩니다.
- **중계소**: 고정 주소가 있는 서버입니다. 각 위키는 자기가 받은 문서를 서명해서 **보내고**, 다른 위키가 보낸 것을 **받아 오기만** 하므로
  공개 주소·공유기 설정이 필요 없습니다. 중계소는 서명과 해시를 바꿀 수 없어서 내용을 조작하지 못합니다(할 수 있는 건 '안 전하기'뿐).
  기본 중계소는 `sources.json` 의 `p2p.hubs` 에 적고, 관리판에서 따로 적을 수도 있습니다.

### 사보타주 방지

누군가 문서를 난수나 거짓 내용으로 바꿔 "최신판"이라며 퍼뜨리는 경우를 막습니다. **믿음은 주소가 아니라 ID 의 검증 실적으로만 쌓입니다.**

- **등급**: 친구(내가 적은 ID) · 검증된 ID(검증 5건 통과, 거짓 0건) · 수습 ID(그 밖).
- **검증**: 갱신기가 나무위키 요청의 20%로, P2P 로 받은 문서를 나무위키에서 직접 다시 받아 맞춰 봅니다(수습 ID 것부터).
  같은 수정 시각에 내용이 다르면 거짓이 확실하므로 그 ID 를 **차단**하고, 그 ID 에게서 받은 문서를 **모두 받기 전으로 되돌린 뒤**
  다시 받을 목록에 넣습니다(친구도 예외 없음).
- **ID 를 새로 만들어도 소용없게**: 새 ID 는 실적이 0 이라 수습부터 다시 시작합니다. 수습 ID 들에게서는 **모두 합쳐** 한 시간에 200개까지만 받으므로,
  공격자가 ID 를 1,000개 만들어도 퍼질 수 있는 양은 늘지 않습니다. 중계소도 처음 보는 ID 를 한 시간에 200개까지만 받습니다.
- **큰 변경은 직접 확인**: 내 문서와 절반 넘게 다른 내용(예: 통째로 난수로 바꾼 문서)은 P2P 로 받지 않고 나무위키에서 직접 받습니다.
- 서명이 맞지 않는 묶음, 미래 시각, 변환기 판이 다른 문서(친구 것 제외)는 받지 않습니다. 받은 문서는 역사에 어느 ID 에서 왔는지 남습니다.
- 한계: 검증되기 전 잠깐은 한 줄짜리 조작 같은 작은 거짓이 보일 수 있습니다(수습 한도로 양을 묶고, 검증에 걸리면 되돌립니다).

### 중계소 열기

중계소는 **항상 켜져 있고 주소가 바뀌지 않는 서버**가 하나 필요합니다. 위키 전체가 필요 없고(최근 30일 동안 오간 문서만 보관),
문서마다 서명과 해시가 붙어 있어 중계소를 거쳐도 내용이 바뀌지 않으므로 작은 무료 서버와 `http://공인IP:포트` 로 충분합니다.

**Oracle Cloud 무료 서버에 열기**

1. [Oracle Cloud](https://www.oracle.com/cloud/free/) 가입(전화번호·카드 확인이 필요하지만 무료 한도 안에서는 청구되지 않습니다).
2. 콘솔 → Compute → Instances → **Create instance**. 이미지는 **Ubuntu**, 모양은 무료(Always Free) 표시가 있는 것
   (Ampere A1 또는 E2.1.Micro). SSH 키를 받아 두고 만듭니다. 공인 IP 가 바뀌지 않게 하려면 네트워크에서 **예약된 공인 IP**를 붙입니다.
3. 콘솔에서 방화벽 열기: 인스턴스 → 서브넷 → **Security List** → **Add Ingress Rules** →
   Source CIDR `0.0.0.0/0`, IP Protocol `TCP`, Destination Port `8080`.
4. SSH 로 접속해서:
   ```bash
   git clone https://github.com/iamtalker/yourwiki && cd yourwiki
   sudo bash server/hub-setup.sh
   ```
   마지막에 나오는 `http://공인IP:8080` 이 중계소 주소입니다.
5. 이 주소를 `sources.json` 의 `p2p.hubs` 에 넣으면 모든 유어위키의 기본 중계소가 됩니다(관리판에서 각자 적어도 됩니다).

- 다른 서버: 파이썬 3.8 이상만 있으면 `python3 scripts/hub_server.py --listen 0.0.0.0:8080` 으로 띄웁니다.
- 위키와 함께 여는 방법도 있습니다: Docker·리눅스에서 `HUB=on` 이면 위키 주소의 `/_hub/` 가 중계소가 됩니다.
- 리눅스·Docker 환경 변수: `P2P=on`, `P2P_HUBS=http://중계소1,http://중계소2`, `P2P_FRIENDS=친구ID1,친구ID2`, `HUB=on`.
- 내 ID 보기: `python scripts/p2p.py wiki --id` (관리판에도 표시).

## 다른 위키로 내보내기 (1.2: MediaWiki · DokuWiki · Markdown)

관리판의 **다른 위키로 내보내기**에서 위키 전체를 다른 위키 엔진용 파일로 바꿉니다(`export/` 폴더).
CPU 여러 개로 나눠 변환하고, 진행 중에는 남은 시간을 보여 줍니다. 전체 문서(약 180만 개)는 CPU 4개 PC 기준 약 1시간 걸리고, 디스크가 3~10GB 필요합니다.

- **MediaWiki**: `yourwiki-mediawiki.xml.gz` → `php maintenance/run.php importDump --report yourwiki-mediawiki.xml.gz`.
  분류는 `Category:`, 틀은 `Template:`(인자 `@이름@` → `{{{이름}}}`)으로 옮깁니다. 표·접기·문법 강조에는 MediaWiki 기본 확장
  (SyntaxHighlight, Math)과 `mw-collapsible` 을 씁니다.
- **DokuWiki**: `yourwiki-dokuwiki.zip` → DokuWiki 폴더에 `data/` 를 덮어 풀고 `php bin/indexer.php`. 분류와 틀은 이름공간으로,
  파일 이름은 DokuWiki 기본 설정(`fnencode = url`)에 맞춥니다.
- **Markdown**: `yourwiki-markdown.zip` → 문서마다 `.md` 하나(GitHub 방식). 모두 한 폴더라 문서 사이 링크가 그대로 이어지고,
  Obsidian 같은 편집기에서 폴더째 엽니다. 합친 칸이 있는 표는 HTML 표, 접기는 `<details>`, 각주는 `[^1]` 로 옮깁니다.
- 명령줄: `python scripts/convert_wiki.py wiki --to mediawiki|dokuwiki|markdown [--out 파일] [--jobs CPU수]`.
- 옮기지 않는 것: 이미지, `#!html`. 틀 문법은 엔진마다 달라 일부는 손으로 고쳐야 할 수 있습니다.
- 모든 문서 끝의 출처·라이선스 고지는 그대로 옮겨집니다. 내보낸 데이터도 **CC BY-NC-SA 2.0 KR** 이니 지우지 마세요.

**그 사이트의 운영 책임은 공개한 사람에게** 있습니다(권리 침해·게시중단 요청 대응 등).
