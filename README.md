# 유어위키 (YourWiki)

나무위키의 모든 글(문서 약 180만 개)을 **내 컴퓨터에서 원터치로** 띄우는 비공식 도구입니다. 편집이 되는 진짜 위키이고, 나무위키 최신판으로 문서를 갱신할 수도 있습니다.
나무위키 운영사와 관계없는 비공식 도구이며, 데이터는 CC BY-NC-SA 2.0 KR(상업적 이용 금지)입니다.

## 써 보기 (Windows)
1. [릴리스](https://github.com/iamtalker/yourwiki/releases/latest)에서 `yourwiki-….zip` 을 받아 풉니다. (디스크 45GB 이상 필요)
2. 폴더 안의 **`유어위키.exe`** 를 더블클릭합니다. 관리판이 열리면 **[설치]** → **[켜기]**.

풀면 최상위에는 이것만 있습니다.

| 이름 | 하는 일 |
|---|---|
| `유어위키.exe` | 실행 파일 |
| `서버설치가이드.html` | 리눅스 서버에 올릴 때의 안내(웹 페이지) |
| `kit/` | 프로그램·도구·설정이 모두 든 폴더 |
| `wiki/` | (설치하면 생김) 내 위키 데이터. 옮기거나 백업할 때는 이 폴더만 |

## 자세한 설명
사용법, 동기화, P2P, 내보내기·가져오기, Docker·리눅스 서버 설치는 **[kit/README.md](kit/README.md)** 에 있습니다.
변경 기록은 [kit/CHANGELOG.md](kit/CHANGELOG.md), 라이선스는 [LICENSE](LICENSE)(코드 MIT)와 [kit/NOTICE.md](kit/NOTICE.md) 입니다.

> 이 저장소는 **코드와 사용법**만 담고, 나무위키 문서 자체는 올리지 않습니다. 데이터는 설치할 때 archive.org(안 되면 Hugging Face)에서 받아 옵니다.
