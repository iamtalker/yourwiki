유어위키 서버 설치 가이드

인터넷에 공개하는 서버(보통 리눅스 VPS)에 유어위키를 올리는 방법입니다. 내 PC에서만 쓸 거라면 유어위키.bat으로 충분합니다.

이 데이터는 CC BY-NC-SA 2.0 KR입니다. 상업적 이용은 금지됩니다. 이 키트를 사용해 광고를 붙이거나 상업적으로 운영하는 것은 라이선스 위반입니다.
공개하는 순간 그 사이트의 운영 책임(권리 침해·게시중단 요청 대응 등)은 공개한 사람에게 있습니다. 사이트 이름에 "나무위키"를 쓰지 마세요.

1. 준비물

  • 리눅스 서버 (Ubuntu 22.04 이상 권장, 64비트 x86 또는 ARM)
  • 디스크 45GB 이상, 메모리 2GB 이상
  • 서버에 SSH 로 접속할 수 있는 상태

2. 필요한 프로그램 설치 (Ubuntu/Debian)

sudo apt update && sudo apt install -y git python3 p7zip-full curl

3. 키트 받기

git clone https://github.com/iamtalker/yourwiki yourwiki-kit && cd yourwiki-kit

4. 설치 (1~2시간)

bash server/install.sh

엔진과 데이터(5.1GB)를 받아 해시를 검증하고 문서 약 180만 개를 넣습니다. 끊겨도 다시 실행하면 이어서 합니다. SSH 가 끊겨도 계속되게 하려면 tmux 나 screen 안에서 실행하세요.

5. 켜기

bash server/yourwiki.sh start

브라우저로 http://서버주소:3000 에 접속합니다. 처음 켤 때는 검색 색인을 만드느라 준비에 시간이 걸립니다. 나무위키 최신판 동기화는 기본으로 켜져 있습니다(robots.txt 준수, 6초에 1건 이하, 차단되면 즉시 중단).

6. 부팅할 때 자동으로 켜기 (선택)

sudo bash server/yourwiki.sh install-service

7. 자주 쓰는 명령

bash server/yourwiki.sh status
bash server/yourwiki.sh stop
LISTEN=127.0.0.1:3000 SYNC=queue bash server/yourwiki.sh start

LISTEN: 받을 주소(기본 0.0.0.0:3000 = 외부 공개). SYNC: auto(기본) / queue(갱신 단추로 요청한 문서만) / off. 한 번 준 값은 yourwiki.conf 에 기억되어 다음부터 그냥 start 해도 그대로입니다. P2P 공유(P2P=on) 등 다른 설정은 README 를 보세요.

8. 공개 전에 할 일

  1. 관리자 계정: 위키에서 처음 가입한 사람이 관리자가 됩니다. 켜자마자 먼저 가입하세요.
  2. 편집 권한: 관리자 설정에서 누구나 / 가입자만 / 읽기 전용 중에서 정하세요.
  3. HTTPS: nginx 나 Caddy 를 3000번 앞에 두면 됩니다. 예) Caddy: reverse_proxy 127.0.0.1:3000
  4. 방화벽: 3000번(또는 80/443) 포트를 여세요.
  5. 연락처: 삭제·권리 침해 요청을 받을 연락처를 위키에 적어 두세요.

이 스크립트들은 베타입니다. 문제가 있으면 https://github.com/iamtalker/yourwiki 에 이슈로 알려 주세요.
